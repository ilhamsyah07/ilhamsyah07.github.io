Monitoring NMS

Implementasi sistem monitoring jaringan terpusat (Network Management System) menggunakan The Dude dan Zabbix untuk pemantauan real-time seluruh perangkat jaringan. Implementation of a centralized network monitoring system (NMS) using The Dude and Zabbix for real-time monitoring of all network devices.

Latar BelakangBackground

Sebelumnya tim jaringan tidak memiliki visibilitas real-time terhadap kondisi perangkat. Gangguan jaringan seringkali baru diketahui setelah ada laporan dari pengguna, sehingga waktu respons lambat dan downtime tidak terdeteksi lebih awal. Previously, the network team had no real-time visibility into device conditions. Network issues were often only discovered after user reports, resulting in slow response times and undetected downtime.

Proyek ini membangun sistem NMS terpusat yang mampu memonitor ratusan perangkat secara bersamaan, mengirim notifikasi otomatis saat terjadi anomali, serta menyediakan dashboard visual untuk analisis performa jaringan. This project built a centralized NMS capable of monitoring hundreds of devices simultaneously, sending automatic notifications when anomalies occur, and providing visual dashboards for network performance analysis.

Monitoring NMS

Implementasi sistem monitoring jaringan terpusat (Network Management System) menggunakan The Dude dan Zabbix untuk pemantauan real-time seluruh perangkat jaringan.

Durasi

2 Bulan

Peran

Network Engineer

Platform

Zabbix & The Dude

Status

Production

Latar Belakang

Sebelumnya tim jaringan tidak memiliki visibilitas real-time terhadap kondisi perangkat. Gangguan jaringan seringkali baru diketahui setelah ada laporan dari pengguna, sehingga waktu respons lambat dan downtime tidak terdeteksi lebih awal.

Proyek ini membangun sistem NMS terpusat yang mampu memonitor ratusan perangkat secara bersamaan, mengirim notifikasi otomatis saat terjadi anomali, serta menyediakan dashboard visual untuk analisis performa jaringan.

Teknologi yang Digunakan

Zabbix The Dude SNMP v2/v3 Linux Ubuntu MySQL Grafana Telegram Bot API

Yang Dikerjakan

  • Instalasi dan konfigurasi Zabbix Server di atas Ubuntu Server 22.04
  • Integrasi SNMP ke seluruh perangkat MikroTik, switch Ruijie, dan access point TP-Link Omada
  • Setup The Dude untuk pemetaan topologi jaringan secara visual dan real-time
  • Konfigurasi trigger & alerting otomatis via Telegram Bot saat perangkat down
  • Pembuatan dashboard Grafana untuk visualisasi bandwidth, uptime, dan latency
  • Pelatihan tim IT internal dalam penggunaan dan pembacaan dashboard monitoring

Latar BelakangBackground

Kampus memiliki beberapa gedung yang membutuhkan koneksi jaringan yang stabil dan cepat. Sebelumnya jaringan menggunakan topologi flat tanpa segmentasi yang menyebabkan broadcast storm dan bottleneck di jam sibuk. The campus had multiple buildings requiring stable and fast network connectivity. Previously, the network used a flat topology without segmentation, causing broadcast storms and bottlenecks during peak hours.

Proyek ini bertujuan merancang ulang infrastruktur jaringan dengan pendekatan hierarchical design (core, distribution, access layer) disertai implementasi VLAN per departemen dan routing dinamis menggunakan OSPF. This project aimed to redesign the network infrastructure using a hierarchical design approach (core, distribution, access layer), along with per-department VLAN implementation and dynamic routing using OSPF.

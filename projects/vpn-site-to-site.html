VPN Site-to-Site WireGuard

Konfigurasi tunnel VPN WireGuard antar kantor cabang untuk mengamankan komunikasi data internal perusahaan lintas lokasi dengan performa tinggi dan konfigurasi yang lebih simpel dibanding solusi VPN konvensional.

Durasi

1 Bulan

Peran

Network Engineer

Platform

WireGuard

Status

Production

Latar Belakang

Perusahaan memiliki beberapa kantor cabang di lokasi berbeda. Sebelumnya komunikasi antar cabang melewati internet publik tanpa enkripsi, sehingga berisiko terhadap intercept data. Solusi VPN lama berbasis IPSec dinilai rumit dikonfigurasi dan overhead-nya tinggi.

Proyek ini memigrasikan infrastruktur VPN ke WireGuard — protokol VPN modern yang lebih ringan, lebih cepat, dan jauh lebih mudah dikonfigurasi. Tunnel dibangun antara kantor pusat dan setiap cabang menggunakan public-key cryptography sehingga seluruh traffic internal berjalan terenkripsi.

Teknologi yang Digunakan

WireGuard Linux Ubuntu MikroTik RouterOS ChaCha20-Poly1305 Curve25519 Public-Key Cryptography UDP Tunnel

Yang Dikerjakan

  • Perencanaan IP addressing dan subnet untuk setiap site (kantor pusat + 3 cabang)
  • Instalasi WireGuard di Linux Ubuntu sebagai VPN server terpusat (hub)
  • Generate keypair (private & public key) untuk setiap peer dan konfigurasi file wg0.conf
  • Konfigurasi WireGuard interface di MikroTik RouterOS untuk sisi cabang
  • Setup AllowedIPs dan routing agar traffic antar subnet cabang melewati tunnel
  • Pengujian koneksi, throughput benchmark, dan dokumentasi konfigurasi lengkap

Hasil & Dampak
